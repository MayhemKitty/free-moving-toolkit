# Free Moving Toolkit

A free, practical toolkit to help people organize and manage a long-distance move.

Moving is expensive, stressful, and full of details to coordinate. This project aims to make the process easier by providing useful tools that anyone can access without paying for a planner or subscription.

## What's included

The initial toolkit is being developed around:

- **Move planning:** Tasks, deadlines, and progress tracking.
- **Provider coordination:** Compare moving services, quotes, and booking details.
- **Budget management:** Track estimates, deposits, balances, and actual expenses.
- **Contingency planning:** Prepare for delays, changes, and unexpected problems.
- **Practical guidance:** A companion guide with checklists and useful reminders.

## Our goal

Make moving easier to manage by providing free, practical resources for people who need them.

The project will start with a downloadable spreadsheet and PDF guide, with the longer-term goal of exploring a more integrated, open-source moving-management application.

## Project status

**In development.** The initial resources are being prepared for release. Downloads and usage instructions will be added when the first version is ready.

## Contributions

Suggestions, feedback, and ideas for improving the toolkit are welcome as the project develops.
